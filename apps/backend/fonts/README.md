# Fonts for PDF Generation

Place Noto font files in this directory for multi-language PDF support.

## Required Files

| Language       | Filename                         | Download from                                              |
|----------------|----------------------------------|------------------------------------------------------------|
| Latin (default)| `NotoSans-Regular.ttf`           | [Google Fonts - Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans) |
| Hindi, Marathi | `NotoSansDevanagari-Regular.ttf` | [Google Fonts - Noto Sans Devanagari](https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari) |
| Bengali        | `NotoSansBengali-Regular.ttf`    | [Google Fonts - Noto Sans Bengali](https://fonts.google.com/noto/specimen/Noto+Sans+Bengali) |
| Arabic, Urdu   | `NotoSansArabic-Regular.ttf`     | [Google Fonts - Noto Sans Arabic](https://fonts.google.com/noto/specimen/Noto+Sans+Arabic) |
| Japanese       | `NotoSansJP-Regular.otf`         | [Noto CJK - JP](https://github.com/notofonts/noto-cjk/releases) |
| Korean         | `NotoSansKR-Regular.otf`         | [Noto CJK - KR](https://github.com/notofonts/noto-cjk/releases) |
| Chinese        | `NotoSansSC-Regular.otf`         | [Noto CJK - SC](https://github.com/notofonts/noto-cjk/releases) |
| Tamil          | `NotoSansTamil-Regular.ttf`      | [Google Fonts - Noto Sans Tamil](https://fonts.google.com/noto/specimen/Noto+Sans+Tamil) |
| Telugu         | `NotoSansTelugu-Regular.ttf`     | [Google Fonts - Noto Sans Telugu](https://fonts.google.com/noto/specimen/Noto+Sans+Telugu) |

**Minimum:** Add `NotoSans-Regular.ttf` for basic Latin support. Add other fonts as needed for your target languages.
